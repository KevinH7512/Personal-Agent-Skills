# 证据与计算核查

按新论文涉及的内容选择使用。这些是写作核查规则，不是对四篇原论文重新做过科学验证的声明。旧报告里的数字、机理和参考文献不能直接迁移到新报告。

## 论断的来源与力度

| 类型 | 适合的表达 | 应保留的信息 |
| --- | --- | --- |
| 直接观察 | 图中显示；作者测得；在该条件下未检出 | 图/表位置、对象、条件、误差或检测限 |
| 作者解释 | 作者据此认为；作者将其归因于 | 支撑解释的证据及其间接性 |
| 自己计算 | 根据文中数据，在……假设下可估算 | 原始输入、公式、单位、计算和适用条件 |
| 自己设想 | 我推测；可能；若……则可通过……检验 | 依据、替代解释、验证途径 |

正文不用强制展示这张表；用自然语言保持区别。发现自己的解释比原文更强时，回查证据，而不是靠措辞模糊处理。

## 图像、谱图与化学结构

- 共定位是空间相关证据，其解释受分辨率、检测灵敏度、信噪比和采集条件限制。不能仅凭元素共定位声称直接证明每个分子的配体始终未解离。
- 比较图像前看比例尺、归一化、颜色范围、曝光、对照和样本数量。图像视觉相似不等于统计检验，相关系数也没有不依赖情境的“稳定性阈值”。
- 比较光谱时区分同一振动模式的峰位移动和不同模式的相对峰强改变。不能只追踪每条谱的最高峰，就当作同一模式的位移。
- 波段、时间和范围中的连字符容易在提取中丢失，例如 `5–7` 被读成 `57`、`2–50` 被读成 `250`。对照页面图像核实，不能根据常识静默修补。
- 不把电子离域、能带排列或选择定则模型写成显微镜直接测得的对象。Ⅰ型、Ⅱ型、准Ⅱ型等分类按本文的实际材料结构、尺寸和证据解释，不套用旧稿。
- 结构式和化合物编号需与新论文一致；说明取代基作用时区分作者明确目的与报告者对设计的理解。

## 统计、模型与泛化

- 不显著不等于证明相同或等效。说明样本量、效应、误差及研究是否实际做了等效性检验。
- 误差条需分清 SD、SEM、置信区间；独立样品数与重复测量次数不混用。缺少这些信息时不输出看似精确的显著性结果。
- Welch 等检验由数据结构与假设决定，不机械沿用样稿的步骤；自由度和尾部选择按原计算保留，不能为了套表任意向下取整。若只能近似，应明确说明。
- 检查训练/测试是否共享样本、批次或生成参数；由同一批实测数据估计分布再产生模拟训练样本，不自动构成独立外部验证。区分重复模拟的稳定性和真实新样本的泛化。
- 稳定性只对实际测试对象、处理条件、时间窗和检测灵敏度成立。一个取代基、体外培养环境或短期测试不能直接代表全部结构、体内环境或长期服役。

## 定量推导与荧光例子

只有推导能回答具体问题时才加入。先列来源、输入、单位和假设，再计算；复算新数据，不照搬样稿结果。

- 单一有效发光态、辐射与非辐射并行一级过程的模型下，可使用 `1/τ = k_r + k_nr`、`Φ = k_r τ`，进而估算 `k_r = Φ/τ`、`k_nr = (1−Φ)/τ`。Φ 用 0–1 的分数；寿命与 Φ 应对应同一对象及相容条件。
- 多指数衰减、态间转移或非均匀体系中，先确定采用的寿命定义及其与 Φ 的关系，不能直接把任意平均寿命代入上述简化关系当作唯一微观速率。
- 多指数预指数幅度、积分强度贡献、粒子数量分数和空间区域比例是不同量；没有额外模型时不能互换，也不能仅凭单指数拟合就证明电子离域。
- 对峰位做简谐振子近似时，只有同一模式且约化质量等条件近似不变，才可用波数比的平方估计力常数比；不能据此定量证明电子转移量。
- 用代码或可复核算式核对推导，保留适当有效数字。明确是否真的进行了拟合、统计检验或数值计算；仅阅读曲线和模型不能声称已经重新拟合数据。

## 评论形成前的自检

1. 这条意见对应哪一个原文或 SI 证据？
2. 作者是否已经回答，或者此问题是否超出本文宣称的范围？
3. 如果存在另一个合理解释，什么追加对照可以区分？
4. 建议的实验能否回答这个问题，新增成本是否与价值相称？
5. 哪一部分是确定的观察，哪一部分仍是我的假设？

未读到关键 SI、误差定义或拟合说明时，保留相应不确定性。不要将“我没有看到”改写成“作者没有做”。
