# 从文献到一道题

## 1. 确定可承载推理的材料

先找核心科学问题，再选数据。优先使用至少能支持其中几项的文献：

- 明确可核对的结构或组成，存在可推导的价态、核数、配位或连接信息。
- 少量反应/循环步骤，能在给定信息后由守恒与成键规律补全。
- 与题目目标相关的实验数据：元素分析、热重、磁性、振动光谱、电势、平衡、速率或晶胞数据。
- 控制变量比较、反常现象、模型检验或有边界的预测。

不要为了凑题使用没有来源的特定键长、磁矩、颜色、产率、失活机制或晶体结构。可用自洽教学数值，但应标为教学设定，不伪称实测。

## 2. 建立轻量事实表

一条关键事实占一行，够追溯即可，不复制论文全文。

| 字段 | 内容 |
|---|---|
| 来源 | 文件名或 DOI；正文/SI 页码、图表号或段落 |
| 事实 | 实际用于题目的数值、结构、反应或观测 |
| 条件 | 物种、溶剂、温度、压力、参比、样品形态等相关条件 |
| 类型 | 实测/作者解释或模型/读图估计/计算派生/教学设定 |
| 用途 | 给定信息、需要推出的答案、合理解释的支持证据 |
| 改编 | 是否改值、简写、删去支路或采用理想模型，以及理由 |

实际使用到的关键图和表须核对原图。PDF 文本可能漏掉桥连、负号、下标、轴单位和图例，不能仅据抽取文本给结构题定答案。

文献可得性和已知条件不能靠猜。多篇论文的数据只有在条件可比时才直接比较，否则分开成题内对照体系，或显式给出教学近似。

## 3. 先写可解的答案骨架

列出最终希望考查的 4—8 个实质动作，不必立即写完整题干，例如：确定形式价态→构造桥连结构→补循环两步→由数据判断电子转移→解释失活。每步写出依据以及是否依赖上一问。

用以下对应关系选择真正需要的约束：

| 目标答案 | 常用的必要约束，按体系选取 |
|---|---|
| 化学式与水合数 | 元素分析、反离子、式量/质量变化、整数范围、结晶水或配位水身份 |
| 核数与桥连 | 组成、金属配位数、配体齿数、端基/桥连类型、等价环境或对称性 |
| 形式氧化态/电子数 | 总电荷、配体形式电荷、所用电子计数约定、必要的非惰性配体约束 |
| 磁性判断 | d 电子数、场强与几何、自旋假定；多核体系必要时说明耦合模型 |
| 反应或循环物种 | 输入输出、计量、配位变化、电荷、电子与质子数 |
| 电势与反应可行性 | 同类电势、参比、介质、相关反应方向和允许的估算假设 |
| 动力学或平衡结论 | 可区分模型的数据、变量定义、测量条件、必要近似 |
| 性质变化原因 | 与该现象有联系的结构/数据证据；有歧义时改成可能解释 |

不是每题都要用到表内所有类型。若需要没有依据的强约束才能使答案唯一，应换材料或改设问，不把自己希望成立的结论硬塞成“实验表明”。

## 4. 把答案骨架转换为题面

开头用短背景交代研究对象与问题。以“研究发现”“实验结果如下”“已知”等自然引出确有来源的信息；教学设定则用“本题采用以下简化模型”“设……”明确标记。

多问围绕同一对象或共同问题推进，给必要结构图/循环图和一张紧凑数据表即可。复杂配体可以用 L、PNP、R 等简写，但必须定义齿数、关键配位原子和电荷；省略部分不得影响所求结构或电子数。

可使用的设问句式：

- 写出……的化学式/离子方程式，系数取最简整数比。
- 画出一种满足上述条件的结构，标出……。
- 计算……，结果保留……，并据此判断……。
- 在图中填入……，标明金属的形式氧化态。
- 比较……并简述理由。
- 根据所给实验现象，给出一种可能原因。

不用所有句式。每个小问说明答案形式、必要单位与枚举范围。不能把作者提出的机理转换为唯一真相；若后问必须采用该机理，应将它作为题设模型。

## 5. 答案、评分与出处

把关键推理写出，不能只给最终结构或数字。结构题接受等价画法；开放解释按“与现象一致、遵守已知条件、给出合理因果链”评分，不要求复述某句原话。

先按推理工作量给分，再核对总分。默认不使用“一处错全题零分”；一个小问结论和理由可以分开给分。前问数值继续使用时，避免重复扣除同一初始误差；必要时给备用值。若用户指定评分方式，则遵从。

命题说明列明来源定位与改编，不把长篇来源核查塞进学生题面；但凡影响可解性或物理意义的假设，必须出现在题面。图和数值的原始来源仍要在交付中可追溯。

题目最终是一道完整题，而不是多个候选题的菜单；除非用户要求多个方案。用户只给论文但未指定分值时，按材料合理完成，不为可自行决定的常规参数反复询问。
