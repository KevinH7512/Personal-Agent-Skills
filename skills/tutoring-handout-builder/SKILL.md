# Tutoring Handout Builder

Support three distinct choices:

- **Concentrated K/Q/A handout:** create a matched student/answer pair and place the retained knowledge section before the retained questions, using the existing concentrated-layout rules unchanged.
- **Interleaved K/Q/A handout:** create a matched student/answer pair and place each retained knowledge group immediately before its owned retained questions, using the existing interleaved-layout rules unchanged.
- **Chemistry handout production:** reconstruct one supplied chemistry study PDF as a clean, naturally paginated, editable Word handout while removing excluded page furniture and using tight source crops only for genuinely graphical material. Produce a separate answer version as well when the user requests it, without overwriting a supplied or user-edited student handout.

The tutor owns content selection, order, difficulty judgment, and classroom design. Preserve those choices. Automate inventory, transcription, scientific-notation reconstruction, diagram handling, formatting, and quality checks; in K/Q/A mode also automate solution checking and matched-version derivation.

Their rendering and repair instructions do not create additional QA rounds. Read relevant resources once per task; reuse their instructions after context compaction rather than restarting discovery.

## Execution calibration for GPT-6 Astra

Give the model a clear deliverable, acceptance criteria, and stopping point. Use its reasoning to settle source grouping, scientific notation, answers, and page allocation in one canonical model; do not compensate with repeated instructions to double-check everything. This calibration follows the [official Astra prompting guidance](https://developers.openai.com/api/docs/guides/latest-model#prompting-best-practices), consulted 2026-09-08, on sensitivity to skill instructions and proportionate verification. The numerical limits below are the user's workflow preferences, not claims about model accuracy.

- Extract each source once and independently solve each question once. Keep the checked result, source mapping, and unresolved points in the canonical model. Revisit only a specific contradiction, unreadable region, or substantive change; a layout edit does not require re-solving unchanged questions.
- Generate both requested versions from that model in one authoring pass. Here, generating a DOCX is distinct from exporting it for visual QA; do not export the answer document as an extra prerequisite to generating the student document.
- Plan page packing from content and answer lengths once. Treat approximate spacing targets as layout guidance, not a reason to run multiple trial exports for cosmetic optimization.
- Reuse available evidence. The included validator is the default structural check; do not add overlapping section, image, ZIP, XML, hash, or Word-reopen audits without a concrete gap or failure that they can resolve. These diagnostics, if needed, stay within the same two-round limit.
- Make ordinary supported choices without an extra approval pause. Briefly report material findings and the delivered files; avoid narrating every tool call or repeatedly promising another final check.

## Non-negotiable output invariants

- Every mathematical fraction or quotient must render as a native stacked Word fraction. In the intermediate equation source, write `\frac{numerator}{denominator}` (for example `\frac{\pi}{6}`), then convert it to OMML containing `m:f`. Never show `π/6`, `1/2`, a Unicode fraction slash, or raw LaTeX commands as a fallback.
- Preserve semantic superscripts and subscripts across subjects. Use native Word run formatting for simple scripts and native Word math for structurally complex expressions; never substitute Unicode subscript/superscript characters or leave formula digits on the baseline. Examples include `x²`, `aₙ`, `v₀`, `CuSO₄`, `SO₄²⁻`, `Fe³⁺`, isotope notation, reaction-condition annotations, and unit powers. In chemistry, stoichiometric coefficients remain baseline, formula atom counts are subscripts, ionic charges and oxidation states are superscripts, and element-symbol capitalization must remain exact.
- Keep mathematical variables italic and units upright where the source and subject convention require it. Keep chemical element symbols and formulas upright.
- Do not draw horizontal separators between questions. Title and section-heading rules may remain, and answer labels may use a restrained left rule, but question blocks themselves must have no top or bottom border. In interleaved mode only, put exactly one subtle thin solid gray rule between adjacent knowledge groups, attached to the following knowledge heading rather than either question.
- In interleaved mode, leave one full `Normal`-line of vertical space between the end of each knowledge block and its first owned question in both versions. Use real paragraph spacing or one genuinely empty `Normal` paragraph; never use typed spaces, nonbreaking spaces, or a decorative rule.
- Student writing space must consist of real empty `Normal` paragraphs, exactly like pressing Enter once for each blank line. Each blank line inherits the normal 10 pt, 1.5-line paragraph settings. Do not use nonbreaking spaces, compressed zero-after paragraphs, fixed-height spacers, blank table rows, or a single tall spacer.
- In every answer version, mark only newly inserted objective-answer text—choice selections, true/false selections, and filled blank content—with dark-red text (`C00000`) plus pale-yellow run shading (`FFF2CC`). Keep the original stem, parentheses, underscores, punctuation, and options in their normal styling. For a written-response, short-answer, or worked-solution answer, put the exact label `答案` alone in its own dark-red paragraph; begin the answer body on the next paragraph and distinguish that body with pale-yellow paragraph shading while keeping its prose and formulas in normal black. Apply the detailed rules in `references/handout-spec.md`.
- On an ordinary three-question page, place the first question immediately below the question heading, the second near one-third of the usable page height, and the third near two-thirds. Start from equal thirds, then adjust the three bands only when the already-written answer lengths clearly justify unequal space. Never vertically center the questions as one group, and never accept the page merely because each question has a fixed 5–6 blank lines.

## Input handling

1. Inventory the supplied folder before writing and select the choice. A single chemistry PDF plus a request for an editable reconstruction activates chemistry handout production even when no `K/Q/A` filenames exist. Otherwise natural-sort ordered filenames such as `K01`, `Q02`, `A03`, including multi-image items such as `Q03a`, `Q03b`, or `Q03-02`. Record gaps, duplicates, unsupported files, and orphan answers before extraction. In interleaved mode, gaps in `K` numbers are intentional grouping instructions rather than missing-file errors.
2. Preserve the user's order. One numbered item may span several images; do not mistake image count for question count. Do not split questions into “例题” and “练习” unless requested. In single-PDF mode, preserve the source's teaching sequence and hierarchy while allowing natural Word pagination.
3. Match text and diagrams by number, continuation cues, adjacency, labels, and mathematical context. Answers are verification evidence, not text to copy blindly. An absent `A` file is not fatal when the question can be solved reliably.
4. Do not stop for ordinary ambiguity. Make the best supported inference and add `【疑点：……】` at the exact relevant location in the answer version. Never place such notes in the student version. Stop only if no question can be recovered or a missing/corrupt source makes the requested output impossible.
5. Use the title supplied by the user. If only a folder name and clear date/subject/topic are available, derive the title in the required format rather than interrupting the workflow.

## Authoring workflow

1. Establish the choice and run once. For concentrated/interleaved K/Q/A work, if the user explicitly chose one, use it; if `K` material exists and neither was given, ask once which of the two to use before authoring. For chemistry handout production, apply the requested inclusion/exclusion boundary and continue without asking about ordinary page-level decisions. For an explicitly declared very large task, accept the user's time budget and start without asking for confirmation.
2. Resolve the run-owned destination path or paths before generating content: exactly two for either K/Q/A choice; for chemistry handout production, exactly one reconstructed student handout by default, or one new answer document alongside the preserved student handout when an answer version is requested. Preserve every file not created by the current run. If a default name already exists, choose a clear suffix once, then keep updating the same run-owned path or pair; never create a chain of revision files.
3. Create one canonical content model before laying out Word pages. In K/Q/A mode, give every knowledge item, group, question, option set, diagram, standard solution, variation, source note, and doubt note an explicit role. In single-PDF mode, give every retained heading, paragraph, list, table, formula, blank, diagram crop, and doubt note a role, and classify excluded page furniture separately. Preserve a source map internally so uncertain text can be traced to its page or image.
4. Complete and check the answer content first. Transcribe ordinary prose as real Word text and reconstruct mathematical expressions as native editable Word math (OMML/Cambria Math); use raster images only for genuinely graphical material. Preserve fraction structure during OCR and authoring: use `\frac{...}{...}` and verify that Word displays a fraction bar rather than a slash.
5. Turn knowledge screenshots into concise editable explanatory text plus relevant figures. Preserve definitions, conditions, units, domains, symbols, and source caveats. Do not invent classroom blanks.
6. For diagrams, keep a tight, legible source crop. Add a clean redraw beside it only when the redraw is faithful and materially improves readability. Do not label the pair “原图” or “重绘图”. If redrawing would require guessing geometry or labels, retain the source crop and place a local doubt note in the answer content.
7. Independently solve each question once, compare with supplied reference answers, and resolve or mark conflicts. Reuse this checked record throughout authoring and QA; repeat reasoning only for the affected question when new evidence changes it. Record granular answer values for choice/true-false/fill-in fields and one standard written solution for each written-response item. Include units, domains, cases, and final conclusions when they matter.
8. Variations are opt-in by instructional value, not a quota. Add no more than two to any one question and normally to no more than about 30% of the set. Each must introduce a new method, structure, boundary case, or conceptual insight and must include a complete solution.
9. Do not add supplemental questions or replace supplied questions unless the user explicitly asks. If asked for supplements, finish all supplied content first and keep the addition within the requested amount and difficulty direction.
10. For either K/Q/A choice, render the answer version first, then render the student version from the same canonical nodes and answer-informed space estimates. The student rendering excludes solutions, variations, doubt notes, and source notes; it must not be created by deleting arbitrary paragraphs from a finished answer file. Question wording, numbering, options, and diagrams must remain identical by construction. In chemistry handout production, render the requested student reconstruction directly from the canonical retained-content sequence; when a separate answer version is requested, build it from the same sequence or from the user-edited student handout as the authoritative baseline, preserving that student file unchanged.
11. Apply the selected layout mode and the fixed specification. In interleaved mode, perform the adjacent-group packing test before allocating the final student writing-space paragraphs, including an active first-page test for two short opening knowledge groups. In ordinary question-only pages, place three question starts around the top, one-third, and two-thirds positions using full-height empty Normal paragraphs informed by answer length; never vertically center the group or add question separators.
12. Save only the selected choice's final Word deliverable(s) in the `output` folder: two files for either K/Q/A choice; one student file for chemistry handout production, or one newly created answer file beside a pre-existing student handout when that is the user's request. Keep content-model caches, crops, renders, PDFs, and other working artifacts in a temporary or `work` location. Ignore Word lock files beginning with `~$`.

## Completion behavior

Continue through transcription, drafting, layout, and bounded validation without asking the user to resolve ordinary uncertainties. Stop checking at the limits below and deliver with an accurate status. If a substantive defect remains, identify it as unresolved rather than labeling the file ready for teaching.

For a normal prepared lesson of no more than ten questions (typically about six), about five student pages, and no more than ten answer pages, target at most fifteen minutes from inventory to delivery. Larger sources or difficult mathematics may need more authoring time, but do not increase the QA round limit. Respect a user-supplied time budget; do not use general quality language to justify open-ended polishing or renderer troubleshooting.

### Verification budget and stopping rules

1. **Round 1:** Run the applicable structural validator once and export each deliverable once for a single page-by-page visual review. Collect findings before making any repair; do not alternate finding one issue, editing, and exporting again. Use `references/qa-checklist.md` as criteria for this review, not as an additional review sequence.
2. **Classify findings:** A wrong answer, omitted condition/question, meaning-changing symbol, student-answer leak, unreadable figure, or clipping that hides teaching content is substantive. Harmless crop-edge text, a redundant bracket, slight whitespace imbalance, or minor decorative inconsistency is cosmetic only if meaning and usability are unaffected. Report cosmetic issues with a question/page location and a brief description in the final response; do not change the file for them unless the user requests it. A stray character that changes a formula is substantive.
3. **Round 2, only if necessary:** Batch the substantive repairs into the same run-owned files, run the validator once more, and export each changed document at most once more. Inspect affected pages and any downstream pagination affected by reflow; do not reread unchanged content or repeat independent solving. If reflow extent is uncertain, inspect the changed document's pages within this round. No third round, fresh regeneration, or additional repair after round 2 unless the user explicitly requests further work. Remaining defects must be disclosed.
4. **Renderer failure:** Check available renderers once. A missing executable is not a reason to attempt launching it. After an actual export failure or timeout, allow at most one evidence-based retry or available fallback in the entire task, counted within the same maximum of two export attempts per document. Do not reset the budget by changing scripts, export APIs, applications, or labeling another attempt a diagnostic. For ordinary handouts, stop an export after 60 seconds without observable progress. End only the run-owned helper when safely identifiable, preserve successful QA evidence, and disclose unavailable visual verification. Do not repair/reinstall Office or build a new rendering pipeline as part of handout QA.
5. **Delivery:** If round 1 reveals no substantive defect, deliver immediately, including any cosmetic notes. Distinguish structural PASS, full visual review, affected-page review, and missing visual review; never claim a full latest-version review that did not occur. Deliver only the final Word file(s) unless PDFs or QA images were requested.
